# 本地配置的读取约定

公开技能不携带个人履历、固定磁盘路径或任何人的投递偏好。

1. 优先读取用户明确给出的配置；否则在本次求职工作目录查找 `job-application.local.md`，并遵循适用的 `AGENTS.md`。不要在整台电脑上搜私人资料。
2. 配置尚不存在时，可参考[配置模板](../assets/project-profile.example.md)。已有会话决定足以开始的阶段直接进行；只询问会改变当前结果的缺项，不要求先填完所有配置。
3. 相对路径以本地配置所在目录解析。无配置时，用户当前工作目录仅作为候选根目录；用户已经明确的基底、目标路径和项目来源优先。
4. 默认建议 `resumes/` 为现有简历目录、`applications/` 为申请输出目录。首次实际写入须已有明确目标路径；不把技能安装目录当申请工作目录。
5. 项目技术事实先读配置列出的一手来源。简历可定位事实与表述，不能据其措辞猜测实现。缺少来源时报告待核实，不编造。
6. 配置只保存路径、偏好与工具选择。个人字段按需从私有资料读取；公开示例不保存联系方式、证件、薪资答案、Cookie 或凭证。

优先使用项目已选的 Python 与工具。`resume_tools.py` 仅用标准库；PDF 阅读、编译及浏览器操作由宿主环境提供。缺能力时交付已完成部分并说明影响，不自动安装依赖或虚报成功。

默认只读外部源码仓库。技能不授予跨仓库修改权限。当前请求、最近明确决定优先于旧状态；地域、学历、批次、薪资等条件保留原适用范围。
