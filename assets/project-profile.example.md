# 求职项目本地配置

复制到自己的求职工作目录，命名为 `job-application.local.md`。本文件只列配置与来源路径；联系方式、证件、薪资答案留在独立私有资料中。
所有相对路径以这份本地配置所在目录为基准，路径不是需要执行的命令。未填写的项目不是已确认事实。

## 工作目录与环境

| 项目 | 你的设置 |
|---|---|
| 称呼与语言 | 按当前对话；默认中文 |
| 项目根目录 | 本配置所在目录 |
| 项目规则 | AGENTS.md（如存在） |
| 现有简历目录 | resumes/ |
| 申请材料输出目录 | applications/ |
| 填表资料 | private/application-info.md（存在时按需读取） |
| Python | 使用项目已选环境；未选时按项目规则确认 |
| Bash | 系统 Bash；Windows 可使用 Git Bash 的实际路径 |
| LaTeX | XeLaTeX；模板需要 ctex、Fandol、geometry、enumitem、hyperref |
| 日期时区 | 使用用户当前时区；未知且影响日期时询问 |
| PDF 命名 | 简历-{公司名}.pdf；可按需填写自己的命名规则 |

## 项目事实来源

逐个列出项目名称、可读取的一手来源、版本或日期、允许访问的范围。

| 项目 | 一手来源路径或链接 | 版本/日期 | 访问范围 |
|---|---|---|---|
| 项目名称（自行填写） | 自己的源码、报告、论文或已确认说明 | 自行填写 | 默认只读 |

## 已确认偏好与约束

- 地点、岗位方向、批次等：按本次请求；长期偏好须注明适用范围。
- 简历页数、栏目、模板：优先沿用基底；不要为适配模板新增履历。
- 项目表述限制、指标口径：按自己的材料填写。
- “至今”必须填精确日期时：仍在进行的项目使用当地执行日期；已结束项目使用真实结束日期，不明则询问。
- AI 工具使用描述：仅在实际经历支持且符合岗位需求时提出建议；不要因 JD 出现 AI 就自动添加。
- 手机审阅：优先可直接查看的可编辑视图；无相关工具时交付可下载 HTML 并说明限制。
- 云端审阅：仅在已授权的服务与访问范围内使用；未授权时先提供本地交付。
- 网申：仅填内容，停在最终提交前。

## 环境记录

首次实际使用时记录选定解释器与可用编译工具，不把示例当成已安装环境。配置与申请记录留在私人工作目录，不提交到技能公开仓库。
